Add chained calculations.

- Pressing an operator while an operation is already waiting applies that waiting operation
  first and shows the running result. After `2 + 3`, pressing the multiply key shows `5`.
- Any number of operations can be chained before equals. `1 + 2 + 3 + 4 =` shows `10`.

Decision — how expressions are evaluated. This holds for the rest of the project:
- The calculator uses immediate execution. Each operator key finishes the operation already
  waiting, strictly left to right. There is no operator precedence.
  `2 + 3 × 4 =` is `20`, not `14`.
- Reason: this is how a pocket calculator works, and it is what makes the running display
  honest. The number on screen is always a real result the user can read and act on. If we
  deferred the multiply, the display would be showing a number the calculator was not
  actually going to use.
