Build a calculator as a single static HTML file named `index.html` in the repo root.

Requirements:
- A display, and a keypad of buttons: digits 0-9, a decimal point, the four operators
  (add, subtract, multiply, divide), equals, and clear.
- Pressing digits builds the current entry and shows it in the display. Pressing 1 then 2
  then 3 shows `123`. The decimal point adds a decimal point to the entry; an entry can
  contain at most one.
- A number, an operator, a second number, then equals shows the result. `7 + 8 =` shows `15`.
- Clear (AC) resets everything. The display shows `0`.
- The display starts at `0`.

Constraints (these hold for the entire project):
- ONE file: `index.html`. Inline CSS and JS. No frameworks, no build step, no CDN links, no network requests.
- The app must work when opened directly from the filesystem.

Test contract — the grader depends on these exact attributes, so use them verbatim:
- `data-testid="calc-display"` — the display element. Its visible text is what the user sees.
  It must also carry `data-value`, holding the exact current value as a plain number string,
  as produced by `String(value)`.
- `data-testid="key-0"`, `key-1`, `key-2`, `key-3`, `key-4`, `key-5`, `key-6`, `key-7`,
  `key-8`, `key-9` — the digit keys
- `data-testid="key-dot"` — the decimal point
- `data-testid="key-add"`, `key-sub`, `key-mul`, `key-div` — the four operators
- `data-testid="key-equals"` — equals
- `data-testid="key-clear"` — clear (AC)
