Add line clears and scoring.

- When a piece locks, every full row is removed and everything above it drops down.
- Count the rows removed in `lines` and show it.

Scoring model — this is a decision, keep it for the rest of the project:
- Points for a clear depend on how many rows go at once:
  1 row = 100, 2 rows = 300, 3 rows = 500, 4 rows = 800.
- That number is multiplied by the current level.
- Soft drop scores 1 point for each cell the piece moves down under the player's control.
- Hard drop scores 2 points for each cell the piece drops.

The reason for the table: clearing rows together must always beat clearing the same rows one
at a time. If it does not, there is no reason for a player to ever build a stack, and the game
has no shape.
