Add a running tape of past calculations.

- `data-testid="calc-tape"` — the tape container
- `data-testid="tape-row"` — one past calculation
- `data-testid="tape-expr"` — the expression, inside the row
- `data-testid="tape-result"` — its result, inside the row. Like `calc-display`, it also
  carries `data-value`, holding the exact result value as a plain number string, as
  produced by `String(value)`.
- `data-testid="tape-clear"` — a button that empties the tape

- A row is added each time equals completes a calculation. Newest row first.
- A row shows the expression and its result. Nothing else — no timestamps.
- Clearing the tape does not change the display.
