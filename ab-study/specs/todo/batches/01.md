Build a todo list app as a single static HTML file named `index.html` in the repo root.

Requirements:
- Add a todo by typing text and clicking an Add button.
- Show all todos in a list.
- Delete a todo.
- Persist todos in `localStorage` under the key `todos`. Reloading the page restores them.
- Each todo has a stable unique `id` and a `createdAt` timestamp.

Constraints (these hold for the entire project):
- ONE file: `index.html`. Inline CSS and JS. No frameworks, no build step, no CDN links, no network requests.
- The app must work when opened directly from the filesystem.

Test contract — the grader depends on these exact attributes, so use them verbatim:
- `data-testid="todo-input"` — the text input
- `data-testid="todo-add"` — the add button
- `data-testid="todo-list"` — the list container
- `data-testid="todo-item"` — each todo row
- `data-testid="todo-text"` — the text inside a row
- `data-testid="todo-delete"` — the delete button inside a row
