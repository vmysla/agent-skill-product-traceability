Add memory keys.

- `data-testid="key-mplus"` — M+, adds the value currently displayed to memory.
- `data-testid="key-mr"` — MR, recalls the memory value into the display.
- `data-testid="key-mc"` — MC, clears memory back to zero.
- `data-testid="mem-indicator"` — shows whether memory is holding anything. It carries
  `data-active="true"` when memory is non-zero and `data-active="false"` when it is zero.

Memory starts at zero. Make sure memory respects the number behaviour we agreed on.
