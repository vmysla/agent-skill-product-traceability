Add completion and filtering.

- Each todo can be toggled complete/incomplete via `data-testid="todo-toggle"` (a checkbox).
- Each `todo-item` must carry `data-completed="true"` or `data-completed="false"`.
- Three filter buttons: `data-testid="filter-all"`, `filter-active`, `filter-completed`.
  They filter which todos are visible. "All" is the default.

Ordering rule — this is a decision, keep it for the rest of the project:
- Completed todos always appear BELOW all active todos.
- Within each group, todos stay in insertion order (oldest first).
